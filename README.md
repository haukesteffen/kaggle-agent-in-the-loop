# Kaggle Agent in the Loop

Currently working on the **Predicting F1 Pit Stops** competition ([Kaggle Playground Series S6E5](https://www.kaggle.com/competitions/playground-series-s6e5)).

## How to run

1. Download the competition data and unzip into `data/raw/`.
2. Create feature recipes by running the notebooks in `feature-engineering/`.
3. Train models and generate OOF and test predictions by running the notebooks in `base-models/`.

## How agents are used

- Brainstorming ideas
- Code reviews
